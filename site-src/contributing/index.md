# How to Get Involved

model-serving-signals is a [Kubernetes](https://kubernetes.io/) project under
[SIG Autoscaling](https://github.com/kubernetes/community/tree/master/sig-autoscaling).
We welcome contributions of all kinds: bug reports, feature requests, documentation, and code.

## Code of conduct

Participation in the Kubernetes community is governed by the
[Kubernetes Code of Conduct](https://github.com/kubernetes-sigs/model-serving-signals/blob/main/code-of-conduct.md).

## Getting started

- [Contributor License Agreement](https://git.k8s.io/community/CLA.md) — Kubernetes projects require a signed CLA before pull requests can be accepted.
- [Kubernetes Contributor Guide](https://k8s.dev/guide) — the main contributor documentation, or jump straight to the [contributing page](https://k8s.dev/docs/guide/contributing/).
- [Contributor Cheat Sheet](https://k8s.dev/cheatsheet) — common resources for existing developers.

See [`CONTRIBUTING.md`](https://github.com/kubernetes-sigs/model-serving-signals/blob/main/CONTRIBUTING.md) for the full guidelines.

## Working on the project

Common starting points once you have a change in mind:

- **Add a signal** — see [Adding a Signal](../extending/adding-a-signal.md).
- **Add an engine** — see [Adding an Engine](../extending/adding-an-engine.md).
